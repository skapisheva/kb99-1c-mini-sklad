# Мини-Склад (1С:Предприятие)

Учебная конфигурация, разработанная в рамках стажировки КБ99. 
Представляет собой минимальный контур учёта для склада.

## Что внутри проекта

### Базовые объекты
*   **Подсистема:** «Мини-Склад» (команды выведены на панель).
*   **Справочники:** Товары, Контрагенты.
*   **Документы:** Поступление, Реализация.
*   **Общие модули:** РаботаСДокументами.

## Как открыть конфигурацию

1. Скачайте все файлы из этого репозитория (кнопка `Code` -> `Download ZIP`).
2. Распакуйте архив в любую папку на компьютере.
3. Запустите **1С:Предприятие** в режиме **«Конфигуратор»**.
4. Создайте новую пустую информационную базу (или откройте существующую учебную).
5. В меню выберите: **«Конфигурация» → «Загрузить конфигурацию из файлов…»**.
6. Укажите папку, в которую вы распаковали файлы из репозитория.
7. Дождитесь завершения загрузки и обновите конфигурацию базы данных (F7).
